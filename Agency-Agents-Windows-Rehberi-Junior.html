🚀 Agency Agents Windows Rehberi

Junior Developer versiyonu - Pratik yaparak öğrenin

📌 Bu Rehber Kimler İçin?

Eğer siz:

  • Windows 10 veya 11 kullanıyorsanız
  • Cursor, VSCode veya benzer bir editör kullanıyorsanız
  • Yapay zeka ajanlarıyla çalışmak isterseniz
  • GitHub'dan repoları klonlamayı biliyorsanız
  • Komut satırı (PowerShell veya Git Bash) ile rahat oluyorsanız

Bu rehber sizin için yazılmıştır. 30 dakikada başlatıp, 4 pratik yapabilirsiniz.

🤖 Agency Agents Nedir?

Basit tanımı: Specialistler havuzu. Her uzman (Frontend Developer, Tasarımcı, Test Mühendisi, vb.) farklı bir işe odaklanır ve çalışma biçimi tanımlanmıştır.

Agency Agents, GitHub'da 279 tane yazılı yapay zeka uzmanıdır. Bunlar bot değildir - kurallardır. Cursor, VSCode veya başka araçlara "bu iş için bu uzman gibi düşün" diye söylediğiniz talimatlar.

Örnek: "Frontend Developer" kuralını Cursor'a taşırsanız, sohbet boyunca Claude (ya da seçtiğiniz AI) bu rolde devam eder. Arayüz kodu yazar, responsive tasarım yapar, en iyi uygulamaları takip eder.

Ajanlar Nasıl Organize Edilir?

279 ajan, 18 bölüme ayrılmıştır:

Bölüm Ne İçin Örnek Ajanlar
Engineering Yazılım geliştirme Frontend Developer, Backend Developer, DevOps Engineer
Design Tasarım ve UX Whimsy Injector, UI Designer, UX Researcher
Testing Kalite kontrol Reality Checker, QA Engineer, Test Automator
Security Güvenlik denetimi Security Engineer, Penetration Tester
Research Kaynak araştırması Research Synthesist
⚠️ Önemli: Tüm 279 ajanı birden kurmayın! Her ajanı yüklediğinizde Cursor'un bağlamı artar, cevaplar yavaşlar. Başlangıçta sadece 3-4 ajan kurun.

📋 Başlamadan Önce Kontrol Listesi

İhtiyacınız Olanlar:

  • Windows 10 veya 11
  • Git for Windows (git-scm.com/download/win)
  • Cursor (cursor.com) veya VSCode + Claude Extension
  • Bir terminal: PowerShell, Git Bash, ya da CMD
  • İnternet bağlantısı

Sürümleri Kontrol Edin:

1

Git'i Kontrol Etme

PowerShell'i açın ve yazın:

git --version

Çıktı: git version 2.42.0.windows.2 gibi bir satır görmelisiniz.

Eğer "git komutu bulunamadı" hatası alırsanız, Git for Windows'u yükleyin.
2

Cursor'u Kurun veya Açın

Cursor uygulaması bilgisayarınızda kurulu ve çalışıyor mu kontrol edin.

🔧 Adım Adım Kurulum (30 dakika)

Adım 1: Repoyu Klonlama

Agency Agents GitHub deposunu bilgisayarınıza kopyalayacağız.

1

PowerShell'i Açın

Başlat menüsüne yazın: PowerShell (veya Windows Terminal)

2

Kullanıcı Klasörüne Gidin

PowerShell'de yazın:

cd $env:USERPROFILE

Bu komutu çalıştırdıktan sonra, klasör yolunuz C:\Users\SizinAdınız olur.

3

Repoyu Klonlayın

PowerShell'de yazın:

git clone https://github.com/msitarzewski/agency-agents.git

Bu işlem 1-2 dakika alacaktır. Tamamlandığında agency-agents klasörü oluşacaktır.

4

Klonun Başarılı Olduğunu Kontrol Etme

PowerShell'de yazın:

cd agency-agents Get-ChildItem agents | Select-Object Name

Beklenen sonuç: 18 klasör adı görmelisiniz: design, engineering, marketing, security, testing vb.

Eğer 18 klasör görüyorsanız, klon başarılı olmuştur! Devam edin.

Adım 2: Pratik Klasörünü Oluşturma

Ajanları kuracağınız ve projeleri yapacağınız ayrı bir klasör oluşturun.

1

Pratik Klasörünü Oluşturun

PowerShell'de yazın:

cd $env:USERPROFILE mkdir ajan-pratik cd ajan-pratik

Şimdi C:\Users\SizinAdınız\ajan-pratik klasöründe bulunuyorsunuz.

Adım 3: Üç Ajanı Kurma

İlk olarak 3 ajanı kuracağız. Bunlar başlangıç için ideal:

1. Frontend Developer

Bölüm: Engineering
HTML, CSS, React, Vue gibi arayüz teknolojilerinde uzman. Responsive tasarım, erişilebilirlik (a11y) ve en iyi uygulamaları takip eder.

2. Whimsy Injector

Bölüm: Design
Tasarımınıza eğlenceli ve anlamlı dokunuşlar ekler. Sadece güzel değil, işlevsel de olur.

3. Reality Checker

Bölüm: Testing
Kodunuzun yayına hazır olup olmadığını kontrol eder. Hataları, güvenlik sorunlarını ve eksiklikleri tespit eder.

Kurulum Komutu

ajan-pratik klasöründe iken şu komutu çalıştırın:

bash "$env:USERPROFILE/agency-agents/scripts/install.sh" --tool cursor --agent engineering-frontend-developer,design-whimsy-injector,testing-reality-checker
Bu komut neyi yapar?
  • --tool cursor: Ajanları Cursor formatında kurar
  • --agent engineering-frontend-developer,...: Üç ajanı belirtir
  • Komut çalıştıktan sonra .cursor/rules klasörü oluşur
1

Kurulum Başarılı Olduğunu Kontrol Etme

PowerShell'de yazın:

Get-ChildItem .cursor\rules

Beklenen sonuç: Üç dosya görmelisiniz:

  • engineering-frontend-developer.mdc
  • design-whimsy-injector.mdc
  • testing-reality-checker.mdc
Bu dosyaları görüyorsanız, kurulum tamamlanmıştır!

Adım 4: Cursor'da Pratik Klasörünü Açma

1

Cursor'u Açın

Bilgisayarınızdan Cursor uygulamasını çalıştırın.

2

Klasörü Açın

File → Open Folder menüsüne tıklayın

Şu yolu seçin: C:\Users\SizinAdınız\ajan-pratik

3

Dosyaları Kontrol Edin

Sol tarafta "Explorer" panelinde:

  • .cursor klasörünü açın
  • rules klasörünü açın
  • Üç .mdc dosyasını göreceksiniz

💡 4 Pratik Uygulama

Pratik Kuralı: Her pratik için yeni bir sohbet açın. Önceki sohbetin rolü yeni işe karışmasın.

Pratik 1: Kişisel Kart (Frontend Developer)

Süre: 10 dakika | Ajan: Frontend Developer | Çıktı: index.html dosyası

1

Cursor'da Yeni Sohbet Açın

"+" simgesine tıklayın veya Ctrl+L tuşuna basın.

2

Ajanı Seçin

Sohbet kutusunda @ yazın.

Açılan listeden @engineering-frontend-developer seçin.

3

Görevi Kopyalayın

Şu metni sohbet kutusuna yapıştırın:

Frontend Developer olarak çalış. Tek dosyalık bir sayfa yaz: kişisel kart. Sayfada şunlar olmalı: - Bir ad alanı - Kendini tanıtan bir cümle (maksimum 10 kelime) - Üç maddelik bir liste (örnek: yetenekler, ilgiler, hedefler) - Bir aksiyon düğmesi (örnek: "Beni İşe Al" veya "Mesaj Gönder") Sayfanın mobil telefonda (smartphone) da okunsun. Dosyayı bu klasöre "index.html" olarak kaydet. Bitince, seçtiğin tasarım kararlarını (renk, font, düzen) beş maddede Türkçe açıkla.
4

Gönder ve Cevabı Bekle

Mesajı gönder. Claude kodu yazacak, index.html dosyası oluşturacak.

5

Sonucu Kontrol Et

File Explorer'de C:\Users\SizinAdınız\ajan-pratik\index.html dosyasını aç.

Veya Cursor'da sağ tıklayıp "Open in Browser" seç.

Beklenen sonuç: Güzel tasarlanmış, mobil uyumlu bir kişisel kart görmelisiniz.

Pratik 2: Yayına Hazır Mı? (Reality Checker)

Süre: 8 dakika | Ajan: Reality Checker | Çıktı: Denetim raporu

Ön koşul: Pratik 1'de oluşturduğun index.html dosyası olmalı.
1

Yeni Sohbet Aç

Ctrl+L ile yeni sohbet başlat.

2

Reality Checker Ajanını Seç

@ yazıp @testing-reality-checker seç.

3

Görevi Kopyala

Reality Checker olarak çalış. Şu dosya var: index.html Bu dosya yayına hazır mı? Kontrol et: - Responsive tasarım: mobil ve masaüstüde çalışıyor mu? - Erişilebilirlik: ekran okuyucu kullanıcıları için uygun mu? - Performans: sayfa hızlı yükleniyor mu? - Tarayıcı uyumluluğu: Chrome, Firefox, Safari'de çalışıyor mu? - SEO: etiketleri ve başlık var mı? Bulduğun tüm sorunları ve önerileri Türkçe listele. 10 puan üzerinden bir puan ver (10 = mükemmel, yayına hazır).
4

Cevabı Analiz Et

Reality Checker ajanı dosyayı analiz edecek ve tavsiyeler verecek.

Bu tavsiyeleri not et, sonraki adımda kullanacaksın.

Pratik 3: Eğlenceli Dokunuş (Whimsy Injector)

Süre: 10 dakika | Ajan: Whimsy Injector | Çıktı: Geliştirilmiş HTML

1

Yeni Sohbet Aç ve Ajanı Seç

Ctrl+L ile yeni sohbet aç, @design-whimsy-injector seç.

2

Görevi Kopyala

Whimsy Injector olarak çalış. Şu dosya var: index.html (kişisel kart) Sayfaya eğlenceli ve işlevsel dokunuşlar ekle: - Hover etkinlikleri (örnek: düğmeye fare gelince rengi değişsin) - Geçiş efektleri (smooth transitions) - İnteraktif animasyonlar (örnek: sayfayı açınca öğeler kayarak gelsinn) - İlginç ama kullanışlı detaylar (örnek: karakterli tipografi) Bu eklemeler sayfanın işlevselliğini bozmasın. Eklediğin her şeyin bir amacı olsun (sadece dekoratif değil). Kodu yazıp dosyayı index.html olarak kaydet. Türkçe olarak: neden bu seçimleri yaptığını ve her efektin amacını açıkla.
3

Sonucu Kontrol Et

Dosyayı tarayıcıda açıp animasyonları ve efektleri gör.

Pratik 4: Tamamlanmış Ürünü İyileştirme (Üç Ajan Beraber)

Süre: 15 dakika | Ajan: Sırayla 3 ajan | Çıktı: Son hali verilmiş sayfa

1

Yeni Sohbet: Frontend Developer

Ctrl+L yeni sohbet, @engineering-frontend-developer seç.

2

Görevi Kopyala

Frontend Developer olarak çalış. index.html dosyasını gözden geçir. İyileştir: - Kod yapısını temizle (semantic HTML) - CSS'i optimize et - Tüm modern tarayıcılarda çalışmasını sağla - Performansı iyileştir Değişiklikleri yap ve dosyayı kaydet. Yapılan değişiklikleri Türkçe listele.
3

Adım 2: Reality Checker

Yeni sohbet aç, @testing-reality-checker seç.

Reality Checker olarak çalış. index.html'i son kez kontrol et. Yayına hazır mı? Evet ise puanla. Hayır ise eksikleri listele ve tavsiye ver.
4

Adım 3: Whimsy Injector (Son Dokunuş)

Yeni sohbet aç, @design-whimsy-injector seç.

Whimsy Injector olarak çalış. index.html'e son kez göz at. Yapılabilecek son eğlenceli ve ince dokunuşlar öner. Varsa kodu yazıp dosyayı güncelle. Öneri olduğu kadar da uygula - son halini kaydet!

🐛 Sık Karşılaşılan Sorunlar ve Çözümleri

Sorun 1: "bash komutu bulunamadı"

?

Hata Mesajı

bash : The term 'bash' is not recognized

✓

Çözüm

Git for Windows yüklü değil veya PATH'te değil. Kurulumu kontrol edin:

& "C:\Program Files\Git\bin\bash.exe" "$env:USERPROFILE/agency-agents/scripts/install.sh" --tool cursor --agent engineering-frontend-developer,design-whimsy-injector,testing-reality-checker

Sorun 2: ".cursor/rules klasörü oluşulmadı"

?

Hata Mesajı

Komut çalıştı ama .cursor\rules klasörü yoksa

✓

Çözüm

Kurulum komutu doğru klasörde çalıştırılmamış olabilir.

cd C:\Users\SizinAdınız\ajan-pratik pwd # Kontrol et, ajan-pratik klasöründe misin? bash "$env:USERPROFILE/agency-agents/scripts/install.sh" --tool cursor --agent engineering-frontend-developer,design-whimsy-injector,testing-reality-checker --dry-run

--dry-run bayrağı dosya yazmadan kurulum planını gösterir. Sonra bayrağı kaldırıp çalıştır.

Sorun 3: "Ajanın cevabı genel, kuralı kullanmamış gibi görünüyor"

?

Belirtiler

Claude aynen yanıt vermiş, Frontend Developer veya Reality Checker gibi davranmamış.

✓

Çözüm

İki nedeni olabilir:

  • Ajan seçilmemiş: @ yazıp doğru ajanı seçtin mi? Sohbet kutusunda ajanın adı görünmelidir.
  • Yanlış klasör açık: Cursor'da açık klasör ajan-pratik mı? File → Open Folder ile kontrol et.
  • alwaysApply ayarı: Bir .mdc dosyasını açıp içine "alwaysApply: true" yazısı var mı? Eğer varsa "false" yap. Sonra @ ile manuel seç.

Sorun 4: Depo klonu "not a git repository" hatası veriyor

?

Hata Mesajı

fatal: not a git repository

✓

Çözüm

Klonu silip yeniden yap:

cd $env:USERPROFILE rm -r agency-agents # Klasörü sil git clone https://github.com/msitarzewski/agency-agents.git # Yeniden klonla cd agency-agents Get-ChildItem agents | Measure-Object # 18 klasör var mı kontrol et

Sorun 5: Cursor'da açılan dosyada index.html oluşmadı

?

Belirtiler

Claude sohbette kodu yazıp gönderdi ama dosya klasörde görünmüyor.

✓

Çözüm

Claude, sohbette göstermesine rağmen dosyayı yazmamış olabilir.

  • Sohbette Claude'dan "dosyayı ajan-pratik klasörine index.html olarak kaydet" diye açıkça iste.
  • Veya sen Cursor'da yeni dosya oluştur (Ctrl+N), kodu yapıştır, Ctrl+S ile index.html olarak kaydet.

🚀 Daha Sonra Öğrenecekler

İlk 4 pratik bittikten sonra, şunları keşfedebilirsin:

1. Yeni Ajanlar Ekleme

Test bölümünün tüm ajanlarını eklemek isterseniz:

cd C:\Users\SizinAdınız\ajan-pratik bash "$env:USERPROFILE/agency-agents/scripts/install.sh" --tool cursor --division testing

--division bayrağı belirli bir bölümün tüm ajanlarını kurar.

2. Diğer Araçlarla Uyumluluk

Cursor yerine VSCode, GitHub Copilot veya diğer araçları kullanmak isterseniz:

Araç Kurulum Komutu Dosya Yolu
VSCode --tool vscode .vscode/extensions/agents
GitHub Copilot --tool copilot ~/.github/agents
Windsurf --tool windsurf .windsurfrules

3. Kendi Ajanını Oluşturma

Depoda şablon dosyaları var. Kendi uzman kurallarını yazabilirsin - örnek: "Türkçe İçerik Uzmanı" veya "API Tasarımcı".

4. Tüm Deposu Öğrenme

279 ajanı incelemek için:

bash "$env:USERPROFILE/agency-agents/scripts/install.sh" --list agents | Out-File agents-list.txt # agents-list.txt dosyasını aç ve göz at
