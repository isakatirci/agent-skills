Agency Agents: Windows'ta sıfırdan pratik rehber

Bu rehber, GitHub deposunu klonlayan biri için hazırlanmıştır. Komutlar sizin çalıştırmanız içindir ve depo gerçek içeriğiyle doğrulanmıştır: 279 kayıtlı ajan, 18 bölüm, scripts/install.sh yükleyicisi.

Bugün izleyeceğiniz sıra

  1. Depoyu git clone ile bilgisayarınıza alın.
  2. Boş bir pratik klasörü açın.
  3. Yükleyiciyle yalnızca üç ajanı o klasöre kurun.
  4. O klasörü Cursor'da açın, .cursor\rules içinde kural dosyalarını görün.
  5. Dört pratiği, her biri yeni bir sohbette olmak üzere sırayla yapın.

Üç ajan:

Ajan Bölüm Dosya adı Ne işe yarar
Frontend Developer Engineering engineering-frontend-developer Arayüz kurar. React, Vue, Angular, sade HTML.
Reality Checker Testing testing-reality-checker İş yayına hazır mı diye kanıta göre denetler.
Whimsy Injector Design design-whimsy-injector Eğlenceli bir dokunuş ekler. O dokunuşun bir işi olmalıdır.

Agency Agents nedir

Her ajan bir uzman tarifidir. Dosyasında kimlik, konuşma biçimi, iş akışı, beklenen çıktı ve başarı ölçüsü vardır. Cursor'da o kuralı seçince sohbet o uzmanın usulüne girer.

Ajan, arka planda kendi başına gezinen bir çalışan değildir. Reddit Community Builder, Reddit üslubunda metin yazar. Sizin adınıza siteye girmez, yorum bırakmaz. Siz isteği yazarsınız, Cursor cevaplar, sonucu siz kaydedersiniz.

Sayının önemi: depoda 279 kayıtlı ajan var (yükleyicinin kendi sayımı). Hepsini bir kerede kurmak, her sohbetin bağlamını boğar. Bu rehberin bütün işi, doğru anda doğru üç ajanı nasıl kuracağınızı göstermektir. 18 bölümün tamamı bu sayfanın sonundaki bölüm haritasında işin içinde.

Lisans MIT'tir. Kişisel pratikte kullanabilirsiniz.

Başlamadan önce

Şunlar yeter:

  • Windows 10 veya 11
  • Cursor (bu sohbetin açık olduğu program)
  • İnternet
  • Git for Windows — rehberin ana yolu bunu kullanır
  • Boş bir klasör

Git for Windows indirme adresi: git-scm.com/download/win. Kurulumda varsayılanlar uygundur. Bitince Başlat menüsünde Git Bash görünür.

Rehber iki kabuk gösterir:

  • Git Bash — ana yol. Ajan metinleri Unix kabuk betiğidir; Git Bash içlerinde çalışır.
  • PowerShell — alternatif yol. Git Bash açmadan, Git for Windows'un içindeki bash.exe üzerinden aynı betikler çalışır.

Rehberdeki komutları iki kabukta da tam haliyle bulacaksınız. Her komutta cd satırı, o klasörün sizin makinenizde yazılması içindir. Komutlar yalnızca install.sh çağırır; başka bir değişiklik yapmaz.

1. Repoyu klonlama

Depo zaten klonlanmışsa bir sonraki başlığa geçin. Değilse:

Git Bash ile

cd /c/Users/isa
git clone https://github.com/msitarzewski/agency-agents.git
cd agency-agents
ls agents

Bu, depoyu C:\Users\isa\agency-agents altına alır. Pratik klasöründen ayrı durur. Bir kez indirmek yeter.

PowerShell ile

cd C:\Users\isa
git clone https://github.com/msitarzewski/agency-agents.git
cd agency-agents
Get-ChildItem agents

agents klasöründe 18 bölüm klasörü listelenmelidir: engineering, design, testing, security, research gibi. Bunları görüyorsanız klon sağlamdır.

Klasör var ama boşsa: Bu, klonun yarıda kesildiği veya temizlenmediği anlamına gelir. git -C C:\Users\isa\agency-agents status "not a git repository" diyorsa klasör bozuk bir kabuktur. İçinde değerli bir şey yoksa silin ve yeniden klonlayın:

cd /c/Users/isa
rm -rf agency-agents
git clone https://github.com/msitarzewski/agency-agents.git

2. Yükleyiciyi tanı

Depo içinden kurulumu yapan tek dosya scripts/install.sh dosyasıdır. Bu dosya agents klasöründeki 279 tarif metnini okur, istediğiniz ajanı seçtiğiniz araca uygun biçime çevirir ve hedef klasöre yazar. Ayrı bir convert.sh adımı da vardır, ama yükleyici onu gerektiğinde kendiliğinden çalıştırır. Siz yalnızca install.sh çağırın.

Önce listeyi görün. Bu, --agent bayrağına yazacağınız adların kaynağıdır:

cd /c/Users/isa/agency-agents
./scripts/install.sh --list agents

Bu liste, ajanın install slug adını yazar: frontend-developer, reality-checker gibi. Dosya adlarıysa bölüm önekiyle başlar: engineering-frontend-developer, testing-reality-checker. İkisi de --agent bayrağına kabul edilir.

Bölüm listesi için:

./scripts/install.sh --list teams

Yazmadan önce ne kurulacağını görmek isterseniz:

./scripts/install.sh --tool cursor --agent engineering-frontend-developer --dry-run

--dry-run hiçbir şey yazmaz, sadece planı yazdırır ve çıkar.

Yükleyici çıktıyı yazmadan önce convert.sh gerektiğinde kendiliğinden çalışır; ayrıca convert.sh çağırmanıza gerek yok. Sonuç birkaç dakika sürebilir. Pencereyi kapatmadan bitmesini bekleyin.

Kurulum nereye yazılır

Yükleyici, --tool bayrağına yazdığınız araca göre hedef klasörü seçer. Ajanlar o klasöre .mdc veya benzeri kural dosyaları olarak düşer.

--path bayrağı ile hedefi elle seçebilirsiniz: --path "C:\Users\isa\ajan-pratik". Varsayılan davranış, komutu çalıştırdığınız klasördür. --link bayrağı kopyalamak yerine symlink yazar; depoyu güncelleyince ajanlar da güncellenir.

3. Üç ajanı kurma

Bu rehberde pratik klasörü C:\Users\isa\ajan-pratik olur. Başka bir klasör seçerseniz aşağıdaki yollarda o klasörü kullanın.

Yol 1: Git Bash

cd /c/Users/isa/ajan-pratik
bash /c/Users/isa/agency-agents/scripts/install.sh --tool cursor --agent engineering-frontend-developer,design-whimsy-injector,testing-reality-checker

cd satırı önce pratik klasörüne geçer. Yükleyici, o anda bulunduğunuz klasöre yazar. bash ile çağırmanız, betiğin dış klasörden çalışmasını sağlar.

Yol 2: PowerShell

cd C:\Users\isa\ajan-pratik
bash "C:\Users\isa\agency-agents\scripts\install.sh" --tool cursor --agent engineering-frontend-developer,design-whimsy-injector,testing-reality-checker

bash komutu Git for Windows'un yüklediği bash.exe dosyasını kullanır. PATH'te yoksa tam yol yazın:

& "C:\Program Files\Git\bin\bash.exe" "C:\Users\isa\agency-agents\scripts\install.sh" --tool cursor --agent engineering-frontend-developer,design-whimsy-injector,testing-reality-checker

Kurulum tuttu mu

Şu klasörde .mdc dosyaları görüyorsanız, kurulum inmiştir:

dir C:\Users\isa\ajan-pratik\.cursor\rules

Bu üç dosya beklenir:

  • engineering-frontend-developer.mdc
  • design-whimsy-injector.mdc
  • testing-reality-checker.mdc

279 ajanı birden kurmayın. Her sohbetin bağlamı dolar, cevaplar yavaşlar ve dağılır. Üç ajanla başlayın. Yeni iş yukarıdaki üç ajanla yapılmıyorsa o işin bölümünü --division ile ekleyin. Bu, Bundan sonra başlığında anlatılıyor.

4. Cursor'da klasörü açın

  1. Cursor'da File > Open Folder.
  2. C:\Users\isa\ajan-pratik klasörünü seçin.
  3. Sol tarafta .cursor ve onun içinde rules görünmeli.
  4. Bir .mdc dosyasını açın.

Dosyanın en üstünde alwaysApply: true yazıyorsa, pratik boyunca bu üç dosyada onu false yapın. Kural o zaman her mesaja kendiliğinden karışmaz. Siz @ ile seçince devreye girer. Anahtar yoksa dosyayı olduğu gibi bırakın ve yine @ ile seçin.

Resmi Cursor örneği şöyledir:

Use the @security-engineer rules to review this code.

Sizde güvenlik ajanı yüklü değildir. Aynı cümle kalıbını, seçtiğiniz uzmanla kullanırsınız.

5. Bir ajanı çağırma

Her pratik için yeni bir sohbet açın. Önceki sohbetin rolü yeni işe taşınmasın.

  1. Sohbet kutusuna @ yazın.
  2. Listeden bu işin kuralını seçin. Ad, Frontend Developer, Reality Checker veya Whimsy Injector diye görünür. Dosya adı da görünebilir.
  3. Aşağıdaki görev metnini yapıştırın.
  4. Gönderin.
  5. Cevap bitince dosyanın klasörde oluştuğuna bakın.

Ajan kendi adıyla ve kendi kontrol listesiyle cevaplıyorsa kural tutulmuştur. Düz, genel bir cevap geliyorsa @ ile kural seçilmemiştir veya Cursor'da açık klasör ajan-pratik değildir.

Görev metinleri Türkçedir. Ajanların kendi metni İngilizcedir. Her görevin son satırı cevabı Türkçe ister.

Aynı anda bir ajan çalışsın. İş bitince diğerine geçin.

Pratik 1: Kişisel kart

Ajan: Frontend Developer. Yeni sohbet. @ ile bu kuralı seçin.

Frontend Developer olarak çalış.

Tek dosyalık bir sayfa yaz: kişisel kart.
İçinde bir ad alanı, bir cümlelik tanıtım, üç madde ve bir düğme olsun.
Sayfa telefonda da okunsun.
Dosyayı bu klasöre index.html olarak kaydet.
Bitince neyi neden seçtiğini beş maddede yaz.
Cevabı Türkçe yaz.

Beklenen sonuç: C:\Users\isa\ajan-pratik\index.html oluşur. Tarayıcıda bu dosyayı açın. Ad, cümle, üç madde ve düğme görünür.

Pratik 2: Yayına hazır mı

Ajan: Reality Checker. Yeni sohbet. @ ile bu kuralı seçin. index.html duruyor olmalı.

Reality Checker olarak çalış.

Bu klasördeki index.html dosyasını yayına hazırlık açısından denetle.
Kanıtı dosyadan çıkar.
Eksik, kırık veya abartılı her maddeyi listele.
Her madde için üç satır yaz: sorun, neden önemli, tek cümlelik düzeltme.
Yeni özellik ekleme. Yalnızca denetim yaz.
Cevabı Türkçe yaz.

Beklenen sonuç: cevap bir övgü paragrafı değildir. Maddeler, dosyada gördüğü şeye bağlıdır. "Her şey mükemmel" deyip geçiyorsa, denetim ajanı seçilmemiştir.

Sayfadaki işi şudur: kanıta dayalı onay, yayına hazırlık, sürüm onayı.

Pratik 3: İşe yarayan bir sevinç

Ajan: Whimsy Injector. Yeni sohbet. @ ile bu kuralı seçin.

Sayfadaki ölçüt: oynak öğe, işlevsel ya da duygusal bir amaca hizmet eder. Süs, okumayı zorlaştırmaz.

Whimsy Injector olarak çalış.

index.html içine tek bir küçük sevinç anı ekle.
Bu ekleme bir işe yarasın: düğmeye basınca ne olduğu anlaşılsın.
Süs, okumayı ve düğmeyi zorlaştırmasın.
Değişikliği dosyaya yaz.
Neden bu hareketi seçtiğini üç cümlede yaz.
Cevabı Türkçe yaz.

Beklenen sonuç: sayfada bir hareket vardır ve düğmenin sonucu hâlâ anlaşılır. Tarayıcıda dosyayı yenileyip düğmeye basın.

Pratik 4: Kısa ekip sırası

Sayfadaki ilk gerçek senaryo bir MVP ekibidir: Frontend Developer, Backend Architect, Growth Hacker, Rapid Prototyper, Reality Checker. Bu pratik o senaryonun kısa halidir. Ekip iki kişidir. Önce arayüz, sonra denetim. İkinci uzman, birincinin metnini görmek için yeni sohbette dosyayı okur.

Konu: tek sayfalık bir haftalık alışveriş listesi. Hesap, sunucu ve üyelik yok.

4a. Arayüz

Yeni sohbet. Frontend Developer.

Frontend Developer olarak çalış.

Tek sayfalık bir haftalık alışveriş listesi yaz.
Ürün adı yazılabilsin, listeye eklensin, işaretlenince üstü çizilsin.

Dosya adı alisveris.html olsun.
Bitince sayfanın nasıl kullanılacağını dört maddede yaz.
Cevabı Türkçe yaz.

Tarayıcıda alisveris.html dosyasını açın. Bir ürün ekleyin, işaretleyin, sayfayı yenileyin. Ürün duruyorsa tarayıcı kaydı çalışıyordur.

4b. Devir

Yeni sohbet. Reality Checker. Bir önceki sohbetin metnini taşımayın. Ajan dosyayı kendisi okusun.

Reality Checker olarak çalış.

alisveris.html dosyasını yayına hazırlık açısından denetle.
Şunları dosyadan kontrol et:
- ürün eklenebiliyor mu
- işaretlenince üstü çiziliyor mu
- sayfa yenilenince liste duruyor mu
- boş ürün eklenebiliyor mu
Her madde için: gözlem, risk, tek düzeltme.
Kodu sen yazma. Denetim raporu yaz.
Cevabı Türkçe yaz.

Raporu okuyun. Düzeltmek isterseniz üçüncü bir sohbet açın, yine Frontend Developer seçin ve rapordaki düzeltme cümlelerini yapıştırın. "Raporun dışına yeni özellik ekleme" satırını da yazın. Böylece ekip sırası bozulmaz: biri yapar, biri denetler, biri yalnızca istenen düzeltmeyi uygular.

Kurulum tuttu mu

Şu dört işaret bir aradaysa pratik tamamdır:

  • ajan-pratik\.cursor\rules içinde en az bir .mdc vardır.
  • Cursor'da açık klasör ajan-pratiktir.
  • Cevap, seçtiğiniz uzman gibi konuşur ve istenen dosyayı yazar.
  • Reality Checker, dosyada gördüğü eksikleri maddeler.

Düz genel cevapta şunlara bakın:

  • Sohbette @ ile kural seçili mi.
  • Açık klasör C:\Users\isa\ajan-pratik mi.
  • Kural dosyası başka bir projenin .cursor\rules klasöründe mi kalmış.
  • alwaysApply: true olan çok sayıda kural aynı anda mı dolmuş. Pratik setinde bu üç dosyada false kalsın.

Bundan sonra nasıl kullanılır

Bir iş, bir uzman, bir çıktı. Mesajın içinde şunlar bulunsun:

  • uzmanın adı
  • üretilecek dosya veya rapor
  • yapmayacağı şey
  • cevap dili

Örnek kalıp:

Frontend Developer olarak çalış.
Şu dosyayı düzenle: index.html
İstenen: düğmenin metnini "Merhaba" yap.
Yapma: yeni sayfa ekleme.
Bitince değişen satırı yaz.
Cevabı Türkçe yaz.

Yeni bir bölüme geçmek istediğinizde, yine hepsini yüklemeyin. Yükleyiciye bölüm adını verin:

cd /c/Users/isa/ajan-pratik
bash /c/Users/isa/agency-agents/scripts/install.sh --tool cursor --division testing

Bölüm adları --list teams çıktısındadır. Masaüstü uygulamada da aynı şekilde daraltın: o günkü işin ekibi.

Sayfadaki diğer çağrı cümleleri, kural seçildikten sonra da çalışır:

Use the Frontend Developer agent to review this component.
Use the Reality Checker agent to verify this is production ready.
