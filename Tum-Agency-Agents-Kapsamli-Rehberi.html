📖 Giriş: Agency Agents Nedir?

Agency Agents, Cursor, Claude, Gemini ve diğer AI araçlarına uzman kimlikler ve iş akışları yükleyen özel rehberlerdir. Bir "ajan" sadece bir bot değildir - bu, AI'ye hangi rolü oynayacağını, nasıl davranacağını ve ne tür çıktılar vereceğini söyleyen bir tariftir.

Neden 279 Ajan?

Yazılım geliştirme, pazarlama, tasarım, topluluk yönetimi, veri analizi gibi 18 farklı alanda 279 özel rol vardır. Bunu şöyle düşünün:

  • Frontend Developer ajan → React/Vue/Angular konularında uzman
  • Whimsy Injector ajan → İşlevlilik + eğlence
  • SEO Specialist ajan → Arama motorları için optimize eder
  • Community Manager ajan → Sosyal medya ve forum yönetimi
  • Security Auditor ajan → Güvenlik açıkları bulur

Bu Rehber Kimler İçindir?

  • ✅ Junior developers (kod yazma alışkanlıkları kazanmak)
  • ✅ Proje yöneticileri (iş akışı optimize etmek)
  • ✅ Tasarımcılar (fikir geliştirmek)
  • ✅ Content creator'lar (yazı ve pazarlama)
  • ✅ Tüm Cursor kullanıcıları (AI'den daha iyi çıktı almak)

⚙️ Kurulum: Adım Adım

Önemli: Tüm 279 ajanı bir kere kurmanız gerekmez! İlk başta 3-5 ajan seçerek başlayın.

Adım 1: Git For Windows Yükle

  1. https://git-scm.com/download/win adresinden Git for Windows'u indir
  2. Kurulumu tamamla (varsayılan ayarlar yeterli)
  3. PowerShell veya Cmd'i yeniden aç ve şunu yazarak kontrol et:
    git --version

Adım 2: Depoyu Klonla

  1. PowerShell'i aç ve istediğin klasöre gitmek için şu komutu çalıştır:
    cd C:\Users\SenAdın\Documents\Projeler
  2. Agency Agents deposunu klonla:
    git clone https://github.com/msitarzewski/agency-agents.git
  3. Klonlanan klasöre gir:
    cd agency-agents
  4. Kullanılabilir ajanları ve bölümleri listele:
    ./scripts/install.sh --list

Adım 3: Ajan Seç ve Kur

  1. Belirli bir bölümdeki ajanları görmek için:
    ./scripts/install.sh --list-agents --division "Software Development"
  2. Cursor praktik klasörü oluştur. Örneğin:
    mkdir C:\Users\SenAdın\Documents\cursor-agents
  3. Seçtiğin ajanları kur:
    ./scripts/install.sh --agents "Frontend Developer,Reality Checker,Whimsy Injector" --tool cursor --target "C:\Users\SenAdın\Documents\cursor-agents"
  4. Kurulum tamamlandıktan sonra kontrol et:
    ls C:\Users\SenAdın\Documents\cursor-agents\.cursor\rules
✅ Başarılı! Şimdi 3 .mdc dosyan bulunmalı. Cursor'u aç ve bu kuralları kullan.

💻 Pratik Örnekler: Ajanları Kullan

Pratik 1: E-Commerce Kişisel Sayfası Yap

Amaç:

Ürünleri satacağın basit bir e-commerce sayfası yap

Kullanacağın Ajanlar:

  1. Frontend Developer - React ile UI yaz
  2. Whimsy Injector - Ürün kartlarına animasyon ekle
  3. Reality Checker - Ödeme işlemi güvenli mi?

Cursor'da Ne Yapacaksın:

# Cursor sohbette şunu yaz: "@Frontend Developer Bir React e-commerce sayfası yap. Ürün listesi gösterilsin ve alışveriş sepetine eklenebilsin." # Sonra: "@Whimsy Injector Ürün kartlarına hover animasyon ekle. Ürün sepete eklenince bir toast notification göster." # Son olarak: "@Reality Checker Güvenlik açıkları kontrol et. Ödeme bilgisi taşıyor mu? XSS riski var mı?"

Beklenen Çıktı:

  • ✅ Çalışan e-commerce sayfası
  • ✅ Eğlenceli animasyonlar
  • ✅ Güvenlik raporu

# Basit (İyi değil): "@Frontend Developer React yaz" # Gelişmiş (Çok iyi): "@Frontend Developer React 18 ile TypeScript kullanarak bir Product List component yaz. - Virtualization kullanın (büyük listeler için) - Accessible olsun (ARIA labels) - Dark mode desteklesin - Loading states gösterilsin"

Workflow: İlk ajan çıktısını sonraki ajana input olarak ver.
Adım 1: @Content Writer makale yaz Adım 2: @SEO Specialist o makalede keyword'ü optimize et Adım 3: @Copywriter o optimized makaleyi sosyal post'a dönüştür Adım 4: @Email Marketer o post'u email newsletter'a dönüştür

3. Custom Ajan Oluştur

İleri seviye: Kendi .mdc dosyanı oluştur.
# custom-agent.mdc örneği: --- name: My Custom Data Analyst type: data personality: | You are a data analyst specializing in startup metrics. You explain complex metrics in simple terms. expertise: - SQL queries - Python data analysis - Chart creation - Growth metrics workflow: | 1. Understand the data structure 2. Write efficient queries 3. Create visualizations 4. Explain insights in business terms ---

4. Ajanları Batch Mode'da Kurulum

Tüm bir bölümü bir kere kur:
# Software Development bölümünün tüm ajanlarını kur ./scripts/install.sh --division "Software Development" \ --tool cursor --target "C:\path\to\project" # Sadece kurulum planını gör (hiç dosya yazma): ./scripts/install.sh --division "Marketing" --dry-run

5. Agentic Loop Oluştur

Konsept: Ajanlar birbirinin çıktısını denetle ve iyileştir.
# Loop örneği: 1. @Content Writer makale yaz 2. @SEO Specialist SEO'yu kontrol et 3. @Grammar Checker yazım hatalarını bul 4. @Content Writer hataları düzelt 5. @Reality Checker yayına hazır mı kontrol et 6. Tekrar 2-5 arası döngü yapılabilir

🔧 Sorun Çözüm

Sorun 1: "Git komutu bulunamadı"

Neden: Git for Windows doğru kurulmadı veya PATH'e eklenmedi
Çözüm:
  1. Control Panel → Programs → Uninstall
  2. Git for Windows'u tamamen sil
  3. Bilgisayarı yeniden başlat
  4. Git for Windows'u yeniden indir ve kur
  5. Kurulum sırasında "Add Git to PATH" seçeneğini işaretle
  6. PowerShell'i yeniden aç ve test et: git --version

Sorun 2: "Ajanlar kurulmadı / Dosyalar .cursor\rules'da yok"

Neden: Kurulum hedef yolu yanlış veya permission sorunu
Çözüm:
  1. Hedef klasörü Windows Explorer'da aç
  2. .cursor klasörü var mı kontrol et (gizli klasör olabilir)
  3. Gizli dosyaları görmek için: View → Hidden Items
  4. Eğer .cursor yoksa manuel oluştur: mkdir .cursor\rules
  5. Kurulum komutunu tekrar çalıştır

Sorun 3: "Depo klonlaması başarısız oldu"

Neden: Network sorunu veya yarım klon
Çözüm:
  1. Klonlanan klasörü sil: rmdir /s agency-agents
  2. İnterneti kontrol et (VPN kullanıyorsan kapat)
  3. Yeniden klonla: git clone https://github.com/msitarzewski/agency-agents.git

Sorun 4: "install.sh script'i çalışmıyor"

Neden: Execution Policy bloğu (Windows güvenliği)
Çözüm:
  1. PowerShell'i Yönetici Olarak Çalıştır
  2. Şu komutu çalıştır:
    Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
  3. Y yazarak onayla
  4. Kurulum komutunu tekrar çalıştır

Sorun 5: "OpenCode runtimeında sadece 119 ajan çalışıyor"

Neden: OpenCode'un ajan limiti var
Çözüm:
  1. Bir bölümün tüm ajanlarını kurma (tüm 279'u değil)
  2. Sadece gerekli 5-10 ajanı seç
  3. OpenCode yerine Cursor kullan (Cursor'da böyle limit yok)

Sorun 6: ".mdc dosyaları Cursor'da görmüyorum"

Neden: Cursor cache'i güncellenmedi
Çözüm:
  1. Cursor'u tamamen kapat
  2. Proje klasörünü Cursor'da tekrar aç
  3. Cmd+K (Mac) veya Ctrl+K (Windows) açarak "@" yazarak ajanları ara
  4. Hala görmüyorsan, .cursor/rules klasöründe dosyalar var mı kontrol et
